# todo

A simple todo app (Ticket #3, issue #4). Create a task, mark it done, delete it.

- **Run:** open `index.html` in a browser. No build step, no server, no dependencies.
- **Storage:** tasks live in the browser's IndexedDB (database `todo-app`, store `tasks`),
  so they survive a page reload. Clearing site data clears the tasks.
- **Status:** done.
